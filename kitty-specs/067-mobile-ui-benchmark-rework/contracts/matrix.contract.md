# Kontrakt: Achsen×Titel-Matrix (`research/matrix.md`)

Zwischenartefakt — Rohbeobachtungen, aus denen D-A/D-B synthetisiert werden.

## Format
Eine Tabelle je Achse (A1–A7). Zeilen = Referenz-Titel, Spalten = Beobachtung + Beleg.

```md
## A1 — Daumen-Zonen/Reachability
| Titel | Beobachtung (was/wie) | Beleg |
|-------|-----------------------|-------|
| Diablo Immortal | … | … |
| Archero | … | … |
| … | … | … |
| **Fogreach (Ist)** | … (Baseline) | js/mobileControls.js |
```

## Pflichten
- Alle 7 Achsen als eigene Tabelle vorhanden.
- Pro Achse ≥2 Referenz-Titel mit nicht-leerer Beobachtung UND Beleg (FR-002).
- Jede Achse enthält die Fogreach-Ist-Zeile als Vergleichsanker (FR-007).
- Beobachtung ≠ Empfehlung (keine Wertung in der Matrix — nur „was/wie").
